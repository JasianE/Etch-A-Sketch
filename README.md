
# Etch-a-Sketch

A browser-based Etch-a-Sketch drawing app built in **2021** as part of **The Odin Project** curriculum.

## Overview

This project was an early exercise in DOM manipulation and event handling. The goal was to recreate a simple drawing experience where users can “sketch” by hovering over a grid.

It helped build foundational skills in JavaScript and front-end development, especially around dynamically creating and updating UI elements.

## Features

- Interactive drawing grid  
- Hover-based drawing (no clicking required)  
- Adjustable grid size  
- Clear/reset functionality  
- Simple and responsive layout  

## Tech Stack

- HTML  
- CSS (Vanilla)  
- JavaScript (ES6)  

## What I Learned

- Manipulating the DOM dynamically  
- Handling user input and events  
- Creating and updating grid-based layouts  
- Writing cleaner, more structured JavaScript  

## Development Notes

This was one of my first front-end projects, so the focus was on functionality over optimization. Looking back, there are many areas that could be improved (performance, structure, and scalability), but it was a key step in building my fundamentals.

## Reflection

While simple, this project played an important role in my early development as a programmer. It reinforced core concepts that I continue to use in more complex applications today.
